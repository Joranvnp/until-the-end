## Codebase Patterns
- Lua modules use `local Module = {}; Module.__index = Module; return Module` pattern
- All entities have `new(x, y, ...)` constructor returning setmetatable instance
- Physics entities share: x, y, vx, vy, width, height, onGround properties
- Collision uses tile-based checking with `collidesWithMap(tilemap)` method
- Drawing functions take `cameraX, cameraY` offsets for world-to-screen translation
- Constants are global (TILE_SIZE, PLAYER_SPEED, etc.) from constants.lua
- Game state stored in global `game` table in main.lua
