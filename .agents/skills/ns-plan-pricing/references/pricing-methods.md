# Pricing Methods

## Evidence ladder

Label the evidence behind every recommendation, strongest first: paid behavior and retention by cohort; interviews and lost-sale reasons; structured willingness-to-pay research; quantified customer value; current official competitor prices; expert heuristics; founder intuition.

## Access model

Self-serve fits when a user reaches a real outcome alone, activation is quick and measurable, free usage cost is bounded, value grows with usage or sharing, and the app is discoverable without procurement. When several fail, recommend paid-first or hybrid.

| Model | Choose when |
| --- | --- |
| Freemium | Free users get durable value, costs stay bounded, expansion creates a natural upgrade |
| Free trial | Value is felt inside a predictable period and continued use is clearly paid |
| Reverse trial | Users must feel premium differentiation first, then fall back to a useful free tier |
| Paid-first | Onboarding is expensive or value needs deep setup |
| Hybrid | Self-serve entry plus assisted sales for larger accounts |

The free boundary must allow the PRD activation event. The paid boundary follows more value, scale, control, or real cost, and is explainable in one sentence before the user hits it.

## Value metric

Score each candidate 1-10 on comprehension, fairness, value correlation, measurability, adoption friendliness, expansion potential, and predictability. A high average is not validation.

## Price hypothesis

`credible monthly value x capture rate (10-30%) = price hypothesis`. Show every assumption. Cross-check against alternatives, budget owner, store commission, and gross-margin floor. Costs set the floor, not willingness to pay.

## Van Westendorp (validation only)

Ask real respondents: too expensive to consider; so cheap quality is doubtful; expensive but worth considering; a bargain. Without responses, list it as an experiment; never fabricate a range.

## Failure modes

- Copying a competitor's trial without modeling this app's value path.
- Gating the core outcome so free users never activate.
- Giving away the expansion metric indefinitely.
- Usage pricing without estimates, caps, or alerts.
- Treating paywall conversion as proof of long-term willingness to pay.
